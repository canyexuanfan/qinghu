# 轻护 · QingHu

基于 Android 无障碍服务的开屏/信息流广告自动跳过工具。安装后开启无障碍开关即可工作，全部识别在本机完成，不上传任何屏幕内容。

> 本项目仅供学习交流。请遵守所在地区法律法规，尊重应用开发者的正当商业利益。

## 功能

- **开屏广告自动跳过**：识别「跳过 / 跳过 5s / 跳過 / Skip」等控件并自动点击（含不可点文字的坐标点按兜底）
- **信息流卡片广告关闭**：按 SDK 类名/尺寸/图标特征匹配关闭按钮
- **摇一摇/互动广告防护**：广告落地页自动返回、外部跳转自动拦截
- **误触防护**：风险区域临时遮罩
- **记录与导出**：已关闭/失败/未拦截三类记录，支持按应用、按时间（含自上次导出以来）导出，用于持续补规则
- **开关即时生效**：首页总暂停、全局能力开关、每应用三态开关
- **存活加固**：前台服务常驻 + 电池优化白名单引导

## 原理

1. 无障碍服务监听窗口事件（TYPE_WINDOW_STATE_CHANGED / CONTENT_CHANGED）
2. 事件在工作线程生成有界节点快照（≤256 节点 / 深度 ≤32 / 密码节点不采集）
3. 规则引擎匹配（文案 / 控件 ID / 类名尾缀 / 兄弟轴 / 子节点数 / 窗口上下文闸门）
4. 多重安全门：敏感窗口（支付/密码/登录）拒绝一切点击；接受类动作（安装/更新/允许）黑名单；窗口必须含广告标识；全局 10 秒 3 次点击限流
5. 点击后自动验证（目标消失才算成功，未生效如实记失败）；同一规则同一应用失败 3 次自动停用

当前内置 **509 条规则**，全部为 target.package = "*" 的全局通用规则（不针对特定应用），按来源分为：自有原创 28 条 + 本项目用户设备观察 3 条（PROJECT-OWNED，随 APK 分发）；社区派生 478 条（李跳跳/GKD 提炼，许可待核，将按「形态 B」移出内置包、改为可停用的推荐订阅，见下文路线）。

与同类工具的差异在**安全模型**：规则来源与许可如实标注、在线更新强制验签、敏感窗口（支付/密码/登录）双重防线、点击后自动验证（未生效如实记失败）、失败自动停用、全局点击限流（10 秒 3 次）。

## 安装使用

1. 下载 `app-standard-release.apk` 安装（minSdk 30，Android 11+）
2. 打开轻护 → 按引导到系统设置开启无障碍开关
3. 返回轻护，首页显示「防护中」即生效

覆盖安装保留全部设置与授权；卸载重装会重置无障碍开关（系统行为）。

## 自行构建

- Android Studio（AGP 8.9.2 / Gradle 8.11.1 / JDK 17）或命令行 `gradle :app:assembleStandardRelease`
- 签名：debug 自动用 debug key；release 需自建 `keystore-local/` 并配置 `signing.properties`
- 规则包位于 `app/src/main/assets/rules/generic_zh.json`（schema 见 `docs/`），修改后重新构建即可

## 隐私

- 所有识别与点击均在本机完成，不上传任何屏幕内容
- 网络权限仅在用户显式开启「在线规则更新」后使用（默认关闭）
- 记录与观察日志存于应用私有目录，可随时在设置中清空或导出
